# Development Plan for 2025-06-02

## Objectives

- Scaffold the initial pytest framework for unit and integration testing.

## Blocker

- The current hap.py CLI does not accept two positional VCF inputs (truth/query) or legacy flags (`-V`, `-X`, `--output-vtc`, `--unhappy`, `--pass-only`, etc.) required by our integration tests.
- Until the CLI is refactored to restore these arguments, end-to-end integration tests cannot pass.

## Prerequisite: CLI refactoring

1. Refactor `src/python/happy/hap.py` to accept:
   - Two positional VCF inputs (truth and query) in order.
   - Legacy flags: `-V/--write-vcf`, `-X/--write-counts`, `--output-vtc`.
   - Mode flags: `--unhappy`, `--pass-only`, and `-l/--chrom`.
   - Core flags: `-r/--reference`, `-o/--report-prefix`.
2. Ensure these CLI options map into the `qfy.quantify` backend correctly.
3. Verify that invoking the refactored CLI with example scripts reproduces expected VCF and summary outputs.
